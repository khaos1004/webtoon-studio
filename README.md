# Webtoon Layout Studio v1.6

Next.js(App Router, TypeScript) 웹툰 레이아웃·효과 편집기.

## 실행
    npm install
    npm run dev      # http://localhost:3000

## 소재 가져오기 (클립스튜디오 등에서 받은 소재)
소재 탭 → 파일 선택 또는 끌어다 놓기.
- 읽을 수 있는 형식: PNG · JPG · WebP · GIF · SVG · PSD(합쳐진 이미지 한 장) · 이 파일들이 든 ZIP
- 읽을 수 없는 형식: 클립스튜디오 전용(.lip .sut .clip .cmc, 3D, 오토 액션). 클립스튜디오에서 PNG로 내보내거나 PSD로 저장해서 올리세요.
- 컷에 붙이기(한 장 / 반복 톤 / 가득) 또는 컷 밖 배경에 놓기. 크기·회전·합성 방식(곱하기·스크린·오버레이·더하기)·잉크 색 조절
- 소재는 이 브라우저(IndexedDB)에 저장되며 외부로 전송되지 않습니다. .wtoon 파일에는 사용한 소재가 함께 들어갑니다.
- 소재 이용 규칙은 소재마다 다르니 내려받은 사이트의 약관을 확인하세요.

## 효과를 쉽게
마술봉·올가미·브러시로 영역 선택 → 원클릭 프리셋 17종 / 개별 효과 21종 → 화면 위 핸들로 방향·거리 조절. 레이어마다 불투명도·숨김·순서.
휘두르기 궤적(초승달 동작선), 소재 붙이기 추가.

## 컷 순서 바꾸기
- 컷 탭: 행을 끌어서 이동, 번호 칸에 숫자를 입력하면 그 자리로 이동(맨 위 0 ~ 맨 아래 끝 번호, 범위를 넘으면 맨 위/맨 아래), ↑↓ 버튼
- 화면: 선택 도구에서 컷 왼쪽 위 번호 손잡이를 끌어 놓을 자리(파란 선)에 놓기. Ctrl+Z 로 취소

## 컷 밖 배경
배경 탭: 바탕색, 단색/그라데이션/패턴/도형/그림 레이어를 컷 뒤·앞에 배치.

## v1.6 내장 효과음 소재
`public/materials/` 에 들어 있는 소재(효과음 217개)가 소재 탭의 “내장 소재”에 처음부터 나와요. 이름 검색 가능, 컷에 붙이거나 컷 밖 배경에 놓을 수 있어요. 컷에 쓴 소재는 .wtoon 파일 안에 그림이 함께 저장돼서, 다른 PC에서 열어도 그대로 보여요.
- `.clip` 파일에서 직접 뽑기: `pip install pillow numpy` 후 `python tools/clip-extract.py 파일.clip public/materials/폴더이름 --prefix 이름`. 레이어를 한 장씩 꺼내 WebP로 저장하고 `public/materials/manifest.json` 에 추가해요(비공식 구조를 읽는 방식이라 모든 .clip 이 되는 건 아니에요).
- 내장 소재는 앱에서 지울 수 없어요(파일을 지우고 manifest 에서 빼면 사라져요). 소재의 이용 규칙은 소재마다 달라서, 배포 시 `public/materials` 를 빼고 배포하세요.
- 데모 페이지(채팅용)에는 내장 소재가 들어 있지 않아요.

## v1.5 효과음 시트 자르기
소재 탭 → “✂ 효과음 시트 자르기…”. 효과음이 한 장에 수백 개 모여 있는 PNG/JPG/WebP/PSD(합쳐진 이미지)를 올리면 한 개씩 자동으로 잘라 소재로 등록해요.
- 투명 배경 PNG를 권장해요(클립스튜디오에서 배경 레이어를 숨기고 PNG로 내보내기). 단색 바탕이면 바탕색을 지워서 인식해요.
- 파란 상자가 소재 한 개이고, 눌러서 빼거나 다시 넣을 수 있어요. “묶는 거리”로 획·테두리를 한 개로 묶는 정도를, “먼지 무시”로 너무 작은 조각을 거를 수 있어요.
- 10000×10000px 시트에서 270개 기준 분석 약 3초 + 등록 약 4초(Chromium 측정). 등록한 소재는 이 브라우저에 저장돼요.
- 이용 규칙은 소재마다 달라요. 내려받은 본인만 쓸 수 있는 소재는 .wtoon 파일을 남에게 줄 때 함께 들어가니 주의하세요.

## v1.4 편의 기능
- 컷 추가(이미지)는 선택한 컷 **바로 뒤**에 들어갑니다.
- 컷마다 위 간격: 컷 탭에서 컷을 고르면 “이 컷 위 간격(px)”(첫 컷 제외). “기본 간격으로 되돌리기”로 해제. 내보내기·.wtoon 에 반영.
- 효과 복사/붙여넣기: 효과 행의 ⎘ 또는 Ctrl+C → 컷 행의 “붙여넣기” 또는 Ctrl+V (묶음은 통째로, 영역 포함).
- 저장: Ctrl+S 는 같은 파일에 덮어쓰기(Chrome/Edge), 다른 이름으로 저장은 Ctrl+Shift+S. 상단에 “✓ 파일명 / ● 저장 안 됨” 표시. 저장 창이 없는 브라우저는 다운로드.
- 화면 이동: Space 누른 채 드래그 또는 마우스 가운데 버튼 드래그.
- 자동저장이 막힌 환경에서는 저장 안 된 채 닫을 때 경고.
- 알려진 한계: 900×3000 컷 전체를 영역으로 잡고 모션/줌 블러·흔들림을 쓰면 계산에 1~3초(웹 워커라 화면은 멈추지 않음). 영역을 좁히면 빨라집니다. `npx tsx test/perf.test.ts` 로 측정.

## v1.7 사용 편의 개선
- **의성어 탭(새로)**: 글자로 바로 만드는 효과음. 웹툰 의성어 280여 개(타격·움직임·폭발·감정·생활음·자연·로맨스·공포) + 스타일 18종(테두리 2겹, 그라데이션, 입체 두께, 잔상, 휘어짐, 들쭉날쭉, 세로쓰기). 화면에서 끌어 옮기고 모서리로 늘리고 위쪽 동그라미로 회전.
- **글꼴**: 말풍선·의성어에 한글 글꼴 20종(Google Fonts). 내보낼 때는 쓰인 글자만 담은 글꼴을 그림 안에 넣어서 PC에 글꼴이 없어도 똑같이 나와요(인터넷 필요).
- **말풍선**: 사각 대사·전화/기계음·떨리는 목소리·독백(검정)·속마음 플래시 추가, 세로쓰기, 굵게, 왼쪽 정렬, 꼬리 두 개.
- **컷**: 사선 컷(위/아래 기울기, 다음 컷과 평행 맞추기), 테두리 두 줄·거친 붓선, 테두리 빠른 설정, 컷 나누기(위치 지정 / N등분).
- **내보내기**: 네이버 도전만화·다음 웹툰리그·일반 웹·인스타그램·X 규격 프리셋, 용량 한도 넘으면 경고.
- **효과**: 영역을 안 골라도 바로 컷 전체에 적용되고, 나중에 영역을 고르면 그 부분으로 바뀜. 패널에서 바로 영역 도구 선택, 프리셋/효과 하나씩 전환.
- **소재**: 두 번 클릭하거나 화면으로 끌어다 놓으면 컷 위에 놓임(옮기기·크기·회전 자유). 선택한 소재의 넣기 버튼이 목록 위에 고정.
- **상단바 정리**: 컷 추가 · 실행취소 · 확대 · 원본 비교 · 열기/저장 · 내보내기 · ⋯(JPG/PNG/PSD/샘플/새로 시작).
